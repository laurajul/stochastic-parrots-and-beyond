# Security Policy

## Supported Versions

This repository publishes a static course website. Only the current content on `main` gets fixes.

## Reporting a Vulnerability

Do not open a public issue for a security problem. A public report tells everyone about the problem before a fix exists.

Send an e-mail to <moritz.maehr@gmail.com>. Include these items:

1. A description of the problem.
2. The steps that show the problem.
3. The affected page, file, or workflow.
4. A possible mitigation, if you know one.

This project follows a 90-day disclosure timeline.

## Report Personal Data

This repository must not contain personal data about participants. If you find a participant name, an attendance record, an evaluation answer, a submission, a certificate, or a signature in the repository or its history, report it privately to the address above. Do not copy the data into an issue.
