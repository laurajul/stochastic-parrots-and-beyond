# Changelog

All notable changes to the course materials are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/). Run `npm run changelog:unreleased` for the commits since the last release. Record changes to teaching content here by hand, with the edition that they affect.

## [Unreleased](https://github.com/maehr/stochastic-parrots-and-beyond/commits/main)

### Added

- Course website for the HS 2026 edition, with a planned FS 2027 edition.
- `data/editions.yml` as the single source for edition facts, and the `edition` shortcode.
- Four lesson pages, each with a documented case: BLOOM, the LAION-5B pathway, safety labeling in Kenya, and the Llama 2 license.
- Panarchy and Ecocycle page, and a facilitator guide for 130 plus 30 minutes.
- Six Reveal.js slide decks with presenter notes.
- Eleven handouts as web pages and tagged PDFs, the Use Statement template as Markdown and Word, and original SVG diagrams.
- Verified bibliography in `references.bib`.
- Tests for edition data, consistency, links, and privacy. CI with pinned actions.

### Status

- The timetable, the case choices, the reading allocation, and the follow-up task are proposals. They await approval by the instructors.
